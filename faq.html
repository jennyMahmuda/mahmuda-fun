Frequently Asked Questions

Do I need an account?

No. The current static site has no sign-up, login, comment account or first-party user database.

What does the cookie popup do?

It asks whether Google Analytics may load. Rejecting keeps analytics disabled. Third-party advertising scripts may have their own cookie behaviour, which is described on the Cookies page.

Where are stories and media managed?

Authors add Markdown stories to story-post/; cover images go in story-post/image/ and video files go in story-post/video/. The full format is documented in guideline.md.

Is Premium active?

Not yet. The Premium page is ready for a future payment provider and gated content, but this static deployment does not currently collect payment.

Will ratings and reviews be added?

Yes, the repository includes a Cloudflare D1-ready schema and integration guide. Until the API is connected, no rating or review data is collected.

How can I report a problem?

Use the social links in the footer or update the repository content through the project owner. Do not submit private or sensitive information in a public review.
